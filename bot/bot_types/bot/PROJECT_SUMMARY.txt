⚡ БЫСТРЫЙ СТАРТ (5 МИНУТ):
═══════════════════════════════════════════════════════════════════════════════

1. Откройте: 00_START_HERE.txt

2. Получите Spotify ключи:
   → https://developer.spotify.com/dashboard
   → Create App
   → Copy Client ID & Secret

3. Создайте Telegram бота:
   → @BotFather
   → /newbot
   → Copy Token

4. Запустите установку:
   Windows: .\setup.bat
   Linux/Mac: ./setup.sh

5. Отредактируйте .env:
   → Вставьте BOT_TOKEN
   → Вставьте SPOTIFY ключи

6. Запустите бота:
   → python main.py
   Или: docker-compose up -d

7. Тестируйте:
   → Напишите боту /start

ПЕРЕД ЗАПУСКОМ ВСТАВЬТЕ В .env:

📱 TELEGRAM:
   BOT_TOKEN = <token из @BotFather>
   
   Как получить:
   1. @BotFather → /newbot
   2. Введите имя и username
   3. Скопируйте токен (вид: 123456789:ABCDefGhIjKlMnOpQrStUvWxYz)

🎵 SPOTIFY:
   SPOTIFY_CLIENT_ID = <Client ID из Dashboard>
   SPOTIFY_CLIENT_SECRET = <Client Secret из Dashboard>
   SPOTIFY_REDIRECT_URI = http://localhost:8000/callback
   
   Как получить:
   1. https://developer.spotify.com/dashboard
   2. Log in / Sign up
   3. Create an App
   4. Copy Client ID и Client Secret
   5. Edit Settings → Redirect URIs → Add http://localhost:8000/callback

🗄️ БД (если Docker - оставьте как есть):
   DATABASE_URL = postgresql+asyncpg://postgres:password@localhost:5432/statify_hub
   REDIS_URL = redis://localhost:6379

⚙️ ОСТАЛЬНОЕ (опционально):
   ADMIN_IDS = 123456789
   LOG_LEVEL = INFO
