📋 STATIFY HUB - ІНСТРУКЦІЯ ДЛЯ WINDOWS
================================================================================

🎵 Це автоматичний Telegram-бот для аналізу Spotify статистики!

================================================================================
⚡ ШВИДКИЙ СТАРТ (всього 5 хвилин):
================================================================================

✅ ШАГ 1: Запуск Setup Скрипту
───────────────────────────────
1. Відкрийте PowerShell або Command Prompt
2. Перейдіть в папку з ботом:
   
   cd bot

3. Запустіть скрипт установки:
   
   .\setup.bat

Це автоматично встановить все необхідне (Python залежності та ін.)


✅ ШАГ 2: Запуск Spotify Dashboard
──────────────────────────────────
1. Перейдіть на https://developer.spotify.com/dashboard
2. Натисніть "Log In" або зареєструйтесь
3. Натисніть "Create an App" 
4. Введіть назву: "Statify Hub"
5. Прийміть умови → "Create"
6. На сторінці додатку скопіюйте:
   ✂️  Client ID → потрібен для .env
   ✂️  Client Secret → потрібен для .env

7. Натисніть "Edit Settings"
8. В полі "Redirect URIs" додайте: http://localhost:8000/callback
9. Натисніть "Save"


✅ ШАГ 3: Запуск BotFather в Telegram
──────────────────────────────────────
1. Відкрийте Telegram
2. Пишіть @BotFather
3. Натисніть /newbot
4. Введіть ім'я бота: Statify Hub Bot
5. Введіть username (буквы+цифры): statify_hub_bot
6. Скопіюйте токен → потрібен для .env


✅ ШАГ 4: Налаштування .env Файлу
──────────────────────────────────
1. В папці "bot" знайдіть файл .env
2. Відкрийте його (правий клік → Edit з Notepad або VSCode)
3. Вставте свої дані:

   BOT_TOKEN=ВАШЕ_ЗНАЧЕНИЕ (від BotFather)
   SPOTIFY_CLIENT_ID=ВАШЕ_ЗНАЧЕНИЕ (з Spotify Dashboard)
   SPOTIFY_CLIENT_SECRET=ВАШЕ_ЗНАЧЕНИЕ (з Spotify Dashboard)
   SPOTIFY_REDIRECT_URI=http://localhost:8000/callback

4. Збережіть файл (Ctrl+S)


✅ ШАГ 5: Запуск PostgreSQL та Redis
─────────────────────────────────────

🔹 Рекомендований спосіб - Docker (най простіше):

1. Завантажте Docker Desktop: https://www.docker.com/products/docker-desktop
2. Встановіть його
3. Відкрийте PowerShell в папці "bot"
4. Запустіть:

   docker-compose up -d

Це запустить PostgreSQL та Redis автоматично!


🔹 Альтернативний спосіб - локально:

PostgreSQL:
   1. Завантажте z https://www.postgresql.org/download/windows/
   2. Встановіть з паролем: password
   3. Знайдіть Program Files → PostgreSQL → bin → pg_ctl.exe
   4. Запустіть з команди або Services

Redis:
   1. Завантажте з https://github.com/microsoftarchive/redis/releases
   2. Встановіть та запустіть redis-server


✅ ШАГ 6: Запуск Бота
────────────────────
1. Відкрийте PowerShell в папці "bot"
2. Запустіть:

   python main.py

3. У консолі повинно з'явитися:
   ✅ Database initialized!
   ✅ Scheduler started!
   ✅ Bot started!


✅ ШАГ 7: Тестування
───────────────────
1. Відкрийте Telegram
2. Напишіть своєму боту (як ви його назвали в BotFather):
   /start

3. Повинна з'явитися кнопка "🎵 Підключити Spotify"
4. Натисніть на неї
5. Авторизуйтесь в Spotify
6. Вернеться в бота

🎉 ГОТОВО! БОТ ПРАЦЮЄ!

🆘 ВИРІШЕННЯ ПРОБЛЕМ:
================================================================================

❌ Помилка: "python: command not found" або "python not in PATH"
→ Python не встановлено. Завантажте з https://www.python.org/
→ При встановленні ОБОВ'ЯЗКОВО виберіть "Add Python to PATH"


❌ Помилка: "pip: command not found"
→ Переустановіть Python з галочкою "pip"
→ Або: python -m pip install -r requirements.txt


❌ Помилка: "ModuleNotFoundError: No module named 'aiogram'"
→ Залежності не встановлені. Запустіть:
  pip install -r requirements.txt


❌ Помилка: "Connection refused" (PostgreSQL)
→ PostgreSQL не запущена
→ Запустіть: docker-compose up -d
→ Або встановіть PostgreSQL локально


❌ Помилка: "Connection refused" (Redis)
→ Redis не запущена
→ Запустіть: docker-compose up -d
→ Або встановіть Redis локально


❌ Помилка: "Invalid BOT_TOKEN"
→ Перевірте, чи правильно скопіювали токен від BotFather
→ Він має вигляд: 123456789:ABCDefGhIjKlMnOpQrStUvWxYz


❌ Помилка: "Invalid client_id" або "Invalid client_secret"
→ Перевірте дані в Spotify Dashboard
→ Переконайтесь, що немає пробілів


❌ Бот не відповідає на /start
→ Переконайтесь, що .env налаштовано
→ Переконайтесь, що PostgreSQL та Redis запущені
→ Переконайтесь, що немає помилок в консолі
