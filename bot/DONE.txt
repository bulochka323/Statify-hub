📋 ЧЕКЛИСТ ДЛЯ ВАС:
═════════════════════════════════════════════════════════════════════════════

☐ КРОК 1: Отримайте Spotify ключі
   → https://developer.spotify.com/dashboard
   → Копіюйте Client ID та Secret
   → Додайте Redirect URI: http://localhost:8000/callback

☐ КРОК 2: Створіть Telegram бота
   → @BotFather в Telegram
   → /newbot
   → Копіюйте Token

☐ КРОК 3: Редагуйте .env
   → Відкрийте bot/.env
   → Вставте BOT_TOKEN
   → Вставте SPOTIFY ключи
   → Збережіть (Ctrl+S)

☐ КРОК 4: Запустіть БД
   → docker-compose up -d
   → Або встановіть PostgreSQL + Redis локально

☐ КРОК 5: Запустіть бота
   → python main.py
   → Або .\launcher.bat

☐ КРОК 6: Тестуйте
   → Пишіть боту /start
   → Авторизуйтесь в Spotify
   → Перегляньте статистику
